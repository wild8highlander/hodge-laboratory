## Движок / The engine

Собственный **арифметический движок произвольной точности на BigInt** (`assets/js/engine/`):

- π через формулу Чудновского с бинарным расщеплением;
- exp/ln/sin/cos/atan — Тейлор с редукцией аргумента;
- Γ через Стирлинга с точными рациональными числами Бернулли (метод сдвига);
- tanh–sinh двойно-экспоненциальные квадратуры с кэшем узлов;
- комплексная арифметика: cbrt для формул Кардано;
- точная целочисленная алгебра: рациональная элиминация, инерция LDLᵀ, **SNF** (Smith normal form).

Все тождества проверены против эталонов `reports/hodge_report.json` и монографии.

## Запуск / Run

```bash
# локально / locally: просто откройте / just open
xdg-open index.html            # Android (Termux): termux-open index.html
# или / or:
python3 -m http.server 8080    # → http://localhost:8080
```

## Публикация / Publish (Android · Termux, Linux, macOS)

```bash
# 1) создайте токен / create a token: GitHub → Settings → Developer settings →
#    Personal access tokens (classic) → scopes: repo, workflow
# 2) из папки репозитория / from the repository folder:
bash scripts/github_push_termux.sh
```

Скрипт проверит токен (строго аккаунт **wild8highlander**), создаст репозиторий
`hodge-laboratory-web`, запушит код и включит GitHub Pages.
Сайт: `https://wild8highlander.github.io/hodge-laboratory-web/`

## Структура / Structure

```

├── index.html                  ← оболочка приложения (11 разделов)
```
