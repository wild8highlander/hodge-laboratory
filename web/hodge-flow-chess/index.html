Слои: тор → K3 → Клейн

Слой тора

Чистый поток: состояние (p, φ), φ ∈ μ₄ = {1, i, −1, −i}; переход — сдвиг по модулю сетки и умножение фазы на i. Пространство состояний конечно: 4WH состояний; моновариант открытия строго растёт — завершимость за t* = lcm(W/gcd(a,W), H/gcd(b,H)).

K3-слой: отражения с торможением

Без заворачивания: когда незаторможенный следующий выход покидает [0,W)×[0,H), компонента отражается (знак меняется) и величина шага умножается на γ = δ⁴/k, δ = π/n. Траектория становится ограниченной — «бильярд с демпфированием»; торможение накапливается.

Клейн-слой: Зингер-порождение порядка 7

К модульному потоку добавляется Зингер-порождение порядка 7: время завершимости умножается на 7/gcd(7,H); при H кратном 7 поток замыкается за исходное время. Ячейки окрашиваются по (r+s) mod 7, маркер несёт 7-сегментное кольцо фазы.

О программе

«Hodge Flow — Шахматная Лаборатория» моделирует в реальном времени «шахматную идею» монографии проекта Лаборатории Ходжа: дискретный поток на шахматной сетке — состояния (p, φ) с фазой μ₄, точное время завершимости t*, моновариант открытия, терминальный цикл как μ₄-орбита.

Теоретический источник — монография «Динамический принцип», часть XV («Дискретный поток на шахматной сетке», «Башни больших матриц») и раздел об эквивариантности шахматной сетки (часть II). Сертификат E доказывает завершимость с точной lcm-формулой; эталонный конвейер 48×48 даёт координатную сверку 48/212/432/114.

Честность пометок: значения с бирюзовой пометкой PASS вычислены в вашем браузере по формулам монографии; фиолетовая пометка «документированный эталон» означает величины из сертифицированного конвейера, которые здесь не пересчитываются, а показываются рядом для сверки.

Обозначения: PASS — проверка пройдена (вычислено); FAIL — нарушение обнаружено (вычислено); «документированный эталон» — значение из конвейера монографии.
