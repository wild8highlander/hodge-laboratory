# reports/ — the protocol plots

Five 600 dpi PNG figures generated by the laboratory (`python3 dynamics.py --plots
reports/plots`). All of them visualize quantities certified by the protocol — the
figures and the numbers cannot diverge, since the same run produces both.

| File | Content | Theorem |
|---|---|---|
| `threat_heatmap.png` | the White threat field Θ(c) of the initial position (magma heatmap over the 8×8 board) | T04 / C6 |
| `mobility_census.png` | the total mobility of each particle on the empty board (bars: 420/336/560/896/1456) | T03 / C3 |
| `billiard_flow.png` | the damped billiard trajectory on the board, γ = π⁴/256: the closing spiral of the flow layer | T06 / C4 |
| `perft_growth.png` | the perft growth 20 → 400 → 8902 → 197281 → 4865609 (log scale) | T08 / C5 |
| `dtm_histogram.png` | the DTM distribution over the KRK and KQK states: how the 32-ply and 20-ply maxima arise | T11 / C8 |

Regeneration:

```bash
python3 dynamics.py --plots reports/plots
```

The figures use DejaVu fonts and `constrained_layout`; the plot code lives in
`dynamics.py::make_plots` and is deterministic — the same seed produces the same
PNG bytes.
