K3

Поле угроз

Потенциальный слой: ΣΘ(c) = Σa(π) — дискретная теорема Фубини. Масса поля 38 на сторону, эквивариантность D4 без пешек, пешечная аномалия 176 = 88 + 88.

TORUS

Лагранжиан

Энергетический слой: E = [M(○) − M(●)] + μ[m(○) − m(●)], μ = 0.1. После 1.e4 белый кинетический член +1.0; поиск минимизирует энергию.

KLEIN

Дискретный поток

Потоковый слой: t* = lcm(W/gcd(a,W), H/gcd(b,H)), демпфирование γ = π⁴/256, память — хеши Цобриста splitmix64 (1562 ключа).
