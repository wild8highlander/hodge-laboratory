# HODGE LABORATORY — апгрейд папки `verification/` до эталонной

Что это: готовый набор файлов для замены/добавления в ваш репозиторий
`wild8highlander/hodge-laboratory`. Структура папки повторяет структуру репозитория —
просто скопируйте содержимое поверх.

## Как применить

```bash
# из корня локального клона репозитория
cp -r /path/to/hodge-verification-upgrade/verification/. verification/
# или скопируйте файлы вручную по тому же дереву путей
git add verification/ && git commit -m "verification/: эталонная документация — 6 README, баннеры, GIF, графики"
```

Изменения затрагивают **только** папку `verification/` (исходники .lean/.c/.rs/.f90/.jl
не тронуты — ни одна программа не изменялась).

## Точность

Все числа перепроверены независимым скриптом (censuses, ранг K3 над ℚ = 20 и по mod-p,
Arf, t*, SNF, Клейн); счётчики проверок сняты с исходников: C — 38 (реальный прогон),
Rust — 32, Fortran — 24, Julia — 14, Lean — 40 теорем + 12 примеров, 0 аксиом.
Единственное, что невозможно было выполнить в этой среде, — сам запуск Lean/Julia/Rust/Fortran
(нет тулчейнов); их описания опираются на исходный код и документированные значения из него.
