The Laboratory

A laboratory in one file

The test menu, calculation parameters, the own-experiment designer, reports and tiled 600 dpi plots — with an RU/EN language switch at any moment.

Launch

One file laboratory.py: banner, language choice, an 11-item menu with colored PASS/FAIL verdicts.

Stands and certificates

The full protocol V1–V9, five stands (torus, K3, Klein, errata E8, binary code), eight certificates.

Your own experiments

The designer accepts arbitrary N, characters (a,b), winding data, CM-lattices and flow parameters — every run receives a mini-certificate.

Reports and plots

JSON + log into reports/ and eight 600 dpi tiles: censuses, the phase lattice, the reflection ladder, braking, the DFT.
